# 05 — الحمولات النافعة والإسقاط الدقيق (مطلب 3 و8، و19: بذور/تشجير)

## 1. نظام الكاسيت المعياري (Belly Cassette)

- حجرة سفلية مركزية بمدخل قابل للسحب في 30 ثانية، أبعاد 320×230×180 مم تقريباً.
- حامل موحّد بموزع قفل (servo + فاصل فيزيائي زائد) — كل حزمة توزن حتى 1.5 kg اسمي (3.0 kg بامتصاص المدى).
- حاوية ذكية مشتركة المعالم: PCM صغيرة، LoRa beacon خفيف، مصير كاميرا files للملاحظة، مستشعر صدمة (SD card للوقائع). ✅‑🟡.

## 2. كتالوج الحمولات (مطلب 3 — ما يتوافق مع الإطار الوزني)

| الفئة | أمثلة معتمدة | قطعة ≈ kg | ملاحظات إسقاط |
|---|---|---|---|
| ماء / غذاء | ميل ماء 0.5L + كتك طاقة 2000 kcal | 0.8–1.2 | مع بطانيات حرارية للبرد |
| طبي طارئ | ضمادات، مضاد نزيف، قفازات، مسكنات | 0.3–0.6 | يعني: الإسقاط يتم عبر رافعة عند الحالات الحرجة |
| أدوية حرجة | أنسولين (packinsulated + gel)، أدرينالين auto-injector | 0.2–0.5 | إجماع بين فريق طبي ميداني + تأكيد بشري صارم |
| دم/جزيئات | شرينات قصيرة مع تبريد سلبي معتمد | 0.4–0.8 | موضوع تحقق معملي؛ يتطلب تكاملاً مع المختبرات الطبية المرخصة |
| AED مصغّر | AED صغير مع تعليمات صوت بالعربية/الإنجليزية | 1.2–1.4 | يسمح النموذج بـ1.5kg أساسي حتى تلك الأسقف |
| اتصالات | BT-LoRa beacon + بطارية AA ×8 + شمعة LED تيتانيوم | 0.3–0.5 | توسع القدرة المحلية للتواصل |
| إبقاء حياة على البرد/ماء | mylar + منقّح مياه (أقراص/مرشح) | 0.4–0.7 | — |
| حريق | كيس مقاوم حريق AB （فوسفات) بخار | ≤0.5 kg per drop | فقط ببرمجة خبير مدني مؤثر، لا استبدال إطفاء أرضي |
| زراعة طارئة | بذور مغلفة + سماد بطيء (عصيدة جل) | 0.2–0.5 | إعادة التشجير/تثبيت كتل الانجراف |
| أدوات صغرى | قاطع seatbelt صغير + مفتاح متعدد + شريحة البدء | 0.2–0.4 | — |

> **منع مطلق**: لا أسلحة ولا متفجرات ولا مواد خطرة ولا حمولات سرية؛ كل حزمة بقائمة علنية وقابلة للتدقيق (ملف 07).

## 3. طرائق الإسقاط (مطلب 8)

| الطريقة | الدقة الهدف | متى تُستخدم | الرباعية |
|---|---|---|---|
| انزلاق حر منخفض (10–25 م) مع وسادة هوائية على الحزمة | CEP 5–10 م | حمولات متسامحة غير حرجة | ✅ |
| **مظلة دائرية موجهة 0.7–0.9 m²** مع steering-servo (GPS/INS خفيف على الحزمة) | CEP ≤ 5 م (هدف) | أدوية/دم/AED | 🧪 يتطلب اختبار إسقاط شامل |
| رافعة سلك Hang-line (25 م، bungee تخميد) | ≤ 2 م | حسّاس/هش (لقاحات، أجهزة) أو منطقة غير صالحة للسقوط الحر | ✅ (نفس المستخدم في لوجستيات) |
| إنزال كامل (هبوط الطائرة) | مثالي | تسليم مباشر للفرق عند الأمان | ✅ |
| عدة حزم في رحلة واحدة | تتوزع عبر مسار (waving pattern) | تغطية متعددة الأهداف | ✅ |

## 4. منطق القرار ذو الحارس (سطراً بسطر)

```
target → تقييم أرضي (flatness+people+danger)
   ├─ طلب تأكيد بشري إلزامي إذا: طبي/دم/تجمع قريب/رياح>8م/ث
   ├─ منع جغرافي: لا إسقاط فوق بشر (حلقة 5 م) ولا فوق بنية هشة
   ├─ اختيار الطريقة: (حساسية H?) → Hang-line ; (سرعة أولى؟) → مظلة موجهة ; (حيوية غير حساسة) → Free-drop
   └─ إسقاط → تأكيد beacon بـ MQTT مشفر → تسجيل الأحداث والمكالمات
```

- **تأكيد الوصول**: LoRa beacon بالحزمة يرسل GPS/nonce؛ تُفكر إن اغتبط الإشارة مع حدث سقوط ثابت. ✅
- **منع فوق البشر**: قبل كل إسقاط، الهيكل الفحص السريع (خوارزمية على الطقم): إن ظهر شخص خلال ≤5م من ECM الخطط في آخر 3 ثوانِ ↛ إسقاط (والتأكيد البشري للاستثناءات فقط).

## 5. إسقاط البذور/إعادة التشجير (إضافة مبتكرة — مطلب 19، ضمن النطاق المدني)
- حزم seed-balls بكتل تربة محيطة + مغلف نشادر خلال مواسم زرع عربية.
- جدولة مع سرب الطائرات (ملف 06) وخريطة رياح دقيقة لتحسين نطاق النمو.
- تُرقَّم كمنفعة بيئية في سجل المهمة بنفس الصرامة الأخلاقية.

## 6. الطاقة والتعقيد الميكانيكي
- بكرة رافعة محركة: 120 g للملف، استهلاك ~20 W عن العبء (تقدير)
- كرتون حزم ذكي: جسم قابل لتسرب الهواء منفماً، لطيف عند الضعف دون إتلاف.
- اعادات الاستخدام: مظلة موجهة يُعاد تجميعها (اختبار تاريخ مراقبة 20 استعمالاً ثم فحص دوري).

## 7. أسئلة مفتوحة للاختبار
1. أداء المظلة الموجهة فعلياً بالريح القطرية (سيناريوهات التوأم الرقمي + Leon ميداني).
2. دقة التحديد beacon العائدة تحت مواد غير مثالية (جيب/ورق شجر).
3. اختبار تحمل الحمولات الحساسة (حماية الأقراص الرقمية والحساسات من صدمة الإسقاط).
