## 1. المهمة (ملخص تنفيذي)

مسح 10–20 كم² بحثاً عن ناجين (بصري/حراري/صوتي/إشارات هواتف)، رسم خرائط 2D/3D وإحداثيات دقيقة، و**إسقاط حمولات نافعة بدقة ≤ 5 م** مع منع الإسقاط فوق البشر، والعمل ليلاً و/أو بدون GNSS، مع توأم رقمي يفحص كل مهمة قبل الطيران، وسرب 2–4 طائرات.

### المواصفات القيادية (Target Spec — تقدير مُعلن)

| البند | القيمة | ملاحظة الصدق |
|---|---|---|
| MTOW | 11.5 kg | تقدير من ميزانية الكتل (ملف 02) |
| باع الجناح | 2.20 m | مفهوم جناح ثابت VTOL مختلط |
| المدى (ذهاب+عودة) | 40–60 km | عند حمولة 1.0 kg؛ يراجع بالقياس |
| زمن الطيران المهمة | 45–120 min | حسب ملف الطاقة المهمة (ملف 02) |
| الحمولة النافعة | 1.5 kg (اسمي) / 3.0 kg (بالمدى المقلص) | وحدات قابلة للتبديل |
| سرعة الانطلاق | 22 m/s / دائرة 8–12 m/s | مفهوم الجناح الثابت |
| مقاومة الرياح | حتى 14 m/s تشغيل، هبوط ~10 m/s | هدف تصميمي، يتحقق بغرفة رياح |
| الارتفاع التشغيلي | 60–150 m AGL | توازن خصوصية × دقة حرارية (تقدير) |
| ضجيج | الهدف ≤ 60 dBA على 100 m | هدف؛ قياس معملي لاحقاً |
| حوسبة طرفية | 30–45 TOPS عند 15–20 W + مسرّع عصبي | ✅ متاح (معمارية الجيل الحالي) |
| دقة إسقاط | ≤ 5 m CEP (مظلة موجهة) / ≤ 2 m (رافعة) | 🧪 تقدير؛ يتحقق باختبارات إسقاط |

## 3. الخلاصة (Recommendation up-front)

> **المفهوم المختار: A — جناح ثابت VTOL مختلط (4 رافعات + دافعة خلفية) ببنية تهليلية من ألياف الكربون وعقد تيتانيوم مطبوعة، دفع كهربائي موزع منخفض الضجيج، بطارية حالة صلبة (خارطة C/D اختيارية) مع مسار احتياطي Li-ion سائد، استشعار مدمج بحراري+LiDAR+GPR نانوي+SDR، وحوسبة طرفية 45 TOPS.**
>
> التفصيل والمبررات في `01-concepts-selection.md` — حيث يتفوق A على B (جسم مندمج بمراوح قنوات) في المدى، وعلى C (أجنحة متحولة الشكل) في التعقيد والاعتمادية والجدول الزمني، مع اقتراض أفضل عنصر من B (سطح مندمج) وعنصر أبحاث من C (أطراف تحكم مرنة) كمسار تطوير D لا كاعتماد نهائي.

**أفضل تجربة تالية (Best Next Experiment, مطلب البرنامج):** بناء حلقة محاكاة الإسقاط الدقيق في التوأم الرقمي (ربط نموذج المظلة الموجهة بمحرّكنا الفيزيائي الحالي + اختبار معيّن في مصفوفة السيناريوهات) قبل أي نموذج أولي مادي. التفصيل في ملف 06 و08.

## 4. افتراضات مُوثقة (يتم إظهارها لكل ملف)

1. البيئة الاستهدافية: كوارث مدنية في مناطق غير متاحة براً (زلازل/فيضانات/جبال/صحراء)، 8 ساعات من إعلان المهمة إلى انطلاق أول طلعة.
2. تشغيل قانوني ضمن أحكام الطيران المدني للبلد المضيف + تنسيق مع الجهات الإغاثية الرسمية فقط.
3. لا حمولة خطرة، لا مواد مدرجة، لا حمولات سرية — كل رحلة بسجل مفتوح قابل للتدقيق (ملف 07).
4. أسعار وميزانيات الأرقام **تقديرات ترتيب-حجم 2026** وليست عروض.
5. كل بند مُوسوم برباعية الصدق؛ وكل حد أدرج كنطاق لا كنقطة واحدة.
