## 2. المعمارية الحوسبية (حافة أولاً، سحابة عند الإمكان)

```
  مرئي ──▶ كاشف أشخاص/مركبات/دخان (مستشفى هجين عائلة YOLO) ─┐
  حراري ──▶ كاشف حراري مقطر (distilled) ───────────────────┤
  صوت ────▶ ASR صغير + مصنّف استغاثة/لهجات ──────────────────┤ طبقة توحيد زمن/مكان
  SDR ────▶ AoA تقريبي + تتبع قناة ─────────────────────────┤ + خريطة خطر ديناميكية
  GPR/LiDAR ─▶ voxels للسطح/الحطام الخفيف ─────────────────┘
                                  │
                كل قرار مؤثر (إسقاط طبي/فوق تجمع ناس)
                                  ▼
                 تأكيد بشري إجباري + سجل قرار مُسبَّب (audit)
```

- العتاد: حاسب مرافق 30–45 TOPS عند 15–20 W (فئة NVIDIA Orin NX أو ما يكافئها 2025–2027) — ✅.
- مسرّع عصبي إضافي (Neuromorphic إن توفر): موجه لأعباء الزمن الحقيقي المتكررة (صوتيات، تتبع)؛ ثباتكم من برنامجنا السابق (~847 GOp/s/W بأدبيات الجيل) يجعل الهدف المرجو <2 W قابل الدفاع بحثياً — 🔬 اختياري الجيل 2+.
- مبدأ فرز الحافة/الأرض: نفس منطق `edge_split.py` في المستودع: وظائف السلامة تبقى **على متن الطائرة** دائماً، وتحليلات غير حساسة بالاذن تُقاد للأرض؛ عند ضعف الرابط تتعزز الحافة لصالح الخصوصية والزمن.

## 3. الذكاء التفصيلي

### 3.1 الكشف والتصنيف
- **كاشف متعدد الوسائط (EO+LWIR+LiDAR)**: هدف F1 ≥ 0.85 عند 100 م للبشر واقفين/منبطحين (هدف تصميمي؛ بروتوكول القياس ملف 08).
- **حالة الهدف (مراقبة لا تشخيص)**: فئات `واقف / متحرك / جالس / منبطح / تحت حطام خفيف (GPR/LiDAR)` — أي إشارة (نبض/تنفس تقريبي عبر الرؤية) تُوسم **مؤشراً أولياً** ولا تغني عن تأكيد المسعف.
- **تتبع + تنبؤ**: ByteTrack-عائلة مع حلقة ثقة؛ تنبؤ مسار قصير (2–4 ث) لإدراك أماكن البحث المعاد.

### 3.2 قرار الإسقاط والأولوية
- مصفوفة أولويات معلنة: **خطر فوري × حالة الهدف × سلامة نقطة الهبوط**.
- قاعدة ثابتة: لا إسقاط فوق بشر إلا بتأكيد بشري + منطقة هبوط مصنفة "معزولة" (تفصيل ملف 05 و07).

### 3.3 التعلم الفيدرالي (خصوصية أولاً)
- تحتفظ كل طائرة ببياناتها الجوهرية محلياً، وترفع أوزاناً/تدرجات مشفرة بعد المهمة إلى مجمّع آمن (FedAvg-class + تشفير وتوقيع).
- النشر: مودات صغيرة مسفَّرة (distilled) تُرسل في إصدارات OTA موقعة (ملف 07).

### 3.4 التعلم المعزّز للملاحة (مقيد بالأمان)
- التدريب فقط في المحاكاة (Gazebo/Isaac) وعلى خطوط شبكية صارمة — سياسة الـ RL **لا تتحكم مباشرة قط**؛ تمر عبر حارس سلامة صلب (نفس فلسفة برنامجنا الحالية) وحدود تصرف مُثبتة (سقف ميل، دفعة، ارتفاع).

### 3.5 الذكاء القابل للتفسير (XAI — إضافة مبتكرة، مطلب 19)
- لكل قرار: خريطة انتباه مرئية/حرارية مع ثقة، وقائمة عوامل مُسبِّبة (بُعد، سرعة ريح، مستوى بطارية، سلامة منطقة)، محفوظة كاملة للتدقيق اللاحق.

### 3.6 ترجمة فورية لنداءات الاستغاثة (إضافة مبتكرة)
- ASR صغير مدفوع على الحافة بالكامل (لا سحابة)، مع TTS لاسلكي إن سمح التنظيم المحلي؛ كل شيء يُسجل للتقرير الإنساني.

### 3.7 كشف الناجين عبر إشارات الهواتف (مطلب 12 + 19)
1. استماع SDR متعدد الأقطاب: نبضات شبكة قديعة (بث PRACH/LTE-band الخام جداً) + شدة الإشارة عبر الزوايا.
2. AoA بالمصفوفة الخفيفة (تقدير 5–15° بحسب الظروف) → دائرة ثقة على الخريطة الحرارية.
3. **رسالة إرشادية**: بث SMS/USSD عند سماح قانوني وتنسيق مع مزودي الاتصال، أو WiFi P2P اللاسلكي — يُسجل كل ذلك في دفتر التدقيق.
4. تعزيز الربط: أرقام أشخاص معروفة (أُنشئت قانونياً من غرفة الطوارئ) تُزيد الثقة وتعدّل الأولويات الإنسانية.

### 3.8 الخرائط الديناميكية للخطر (إضافة مبتكرة)
- خريطة حيّة 25×25 م للمنطقة: حرارة حياة + غاز/dعابغ + حطام متحرك → درجة خطورة تتغير خلال المهمة، وتغذّي ترتيب الأهداف ومسارات السرب.

## 4. الطاقة وكفاءة الذكاء (نظرة الجودة: W/ TOPS/ زمن)

| حمل الحوسبة | متوسط W | ملاحظة |
|---|---|---|
| Vision خفيف فقط | ~4–6 W | فلسفة برنامجنا الحالية (حدث/مقطر) |
| كامل مجموعة الإدراك | ~18–24 W | اضغط مع منحنى hover |

## 5. حدود الصدق التي لا تُطمس
- **GPR الجوي قصير المدى جوهرياً**: لا يعطي "رؤية عبر الخرسانة العميقة" — لا نعد بذلك.
- **الاستشعار الحيوي بالكاميرا الحرارية مؤشر أولي لا قراراً طبياً**.
- **عمل SDR مع الهواتف** يحتاج سماحاً تنظيمياً وتنسيقاً مع المشغل — دون ذلك يكون سماع سلبي فقط (لا إرسال).
- التصنيف الطبي التفصيلي (واعٍ/غير واعٍ) يُراجع أخلاقياً كلما تحسنت الدقة لتجنب سوء التفعيل.
